# Durka
__Escape from Durka___  
Простой рейкастер-хоррор, написанный на C++, имитирующий 3D-графику с помощью техники raycasting.  

__Особенности__  
• Рендеринг 3D-вида из 2D карты  
• 10 случайно генерируемых комнат  
• Санитары, которые преследуют игрока  
• Система здоровья и регенерации  

__Управление__  
• Движение: W A S D  
• Взгляд: Мышь  
• Бег: Shift  
• Пауза: ESC  
• Рестарт: R (после смерти)
